# Live Simulator

Мобильное веб-приложение, имитирующее интерфейс прямого эфира: камера телефона на весь экран, счётчик зрителей, поток комментариев, сердечки, сценарии для съёмки постановочных роликов.

Это автономный симулятор. Он не подключается к Instagram и другим сервисам, ничего не транслирует, не использует платные API. Все зрители и комментарии генерируются локально в браузере. Видео камеры никуда не отправляется. В кадре всегда есть небольшая метка **SIMULATION**, отключить её в настройках нельзя.

## Самый простой способ: опубликовать на Cloudflare Pages без программирования

В архиве уже есть готовая собранная папка **`dist`**. Её достаточно загрузить. Node.js устанавливать не нужно.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com), это бесплатно.
2. Откройте **Workers & Pages → Create → Pages → Upload assets** (в новом интерфейсе может называться «Drag and drop your files»).
3. Придумайте имя проекта, например `my-live`, и нажмите **Create project**.
4. Перетащите **содержимое папки `dist`** (или саму папку) в окно загрузки и нажмите **Deploy site**.
5. Через минуту появится адрес вида `https://my-live.pages.dev`. Он сразу работает по HTTPS, а это обязательно для камеры на iPhone.

Для обновления: **Pages → ваш проект → Create new deployment**, затем загрузите новую папку `dist`.

### Установка на iPhone как приложение (PWA)

1. Откройте адрес в **Safari**.
2. Нажмите «Поделиться» → **«На экран „Домой“»**.
3. Запускайте с иконки. Интерфейс откроется без адресной строки Safari.

Ограничения Safari, которые обойти нельзя:
- Системная строка состояния iOS (время, батарея) остаётся видна.
- При блокировке экрана iOS останавливает камеру. После разблокировки приложение само перезапустит камеру. Если этого не произошло, нажмите «Повторить».
- Разрешение на камеру Safari может спрашивать заново после перезапуска. Это поведение iOS.

## Как пользоваться

- **Начать эфир**: включаются камера, чат, счётчик и сердечки.
- **⋯** в нижней панели открывает управление. Панель полупрозрачная и закрывает только нижнюю часть кадра.
  - **Эфир**: ник и фото стримера, зрители (пресеты 120 / 1 200 / 12K / 75K / 250K / 1M или свои значения от 1 до 1 000 000), скорость и сила колебаний, активность чата (спокойный / активный / очень активный), язык (RU / UA / EN / микс), тематика (общая, покер, игры, музыка, улица), пауза комментариев, входы зрителей, сердечки, переключение камеры, сброс.
  - **Режим записи**: таймер эфира, запуск, пауза и остановка сценария, ручная реплика от любого ника, создание и редактирование сценариев, сохранение в файл и загрузка из файла.
- **Тап по аватару** в шапке сразу открывает «Режим записи».
- **Двойной тап по видео** или кнопка ♡ запускают всплеск сердечек.
- Строка «Комментарий…» отправляет сообщение от имени стримера.
- **✕** завершает эфир.

Все настройки и сценарии сохраняются в браузере (localStorage) и переживают перезагрузку.

### Формат сценария

Одна строка соответствует одному событию:

```
# комментарий — строка игнорируется
0:00 !viewers 340              — счётчик сразу 340
0:02 anya.koval: привет!!      — сообщение от ника в момент 0:02
+3 о, эфир                     — через 3 с после предыдущего, от случайного зрителя
просто текст                   — через 1,5 с после предыдущего
0:06 !viewers 75k 20s          — плавно довести счётчик до 75 000 за 20 с
!chat calm|active|hyper|off    — активность случайного чата (off — только реплики сценария)
!hearts 40                     — всплеск сердечек
```

У каждого сценария, помимо таймлайна, есть: начальное число зрителей, режим случайного чата и скорость воспроизведения (0,5–2×). Кнопка «Сохранить в файл» создаёт `live-scenarios.json`. Этим файлом можно поделиться или загрузить его на другом устройстве через «Загрузить файл».

## Для разработчика

Стек: React 19 + TypeScript + Vite + Tailwind CSS 4, PWA (manifest + service worker), без backend.

```bash
npm install
npm run dev          # http://localhost:5173 (на компьютере камера работает и по http://localhost)
npm run dev:https    # HTTPS по локальной сети — чтобы открыть с iPhone (примите предупреждение о сертификате)
npm test             # тесты движков (vitest)
npm run build        # сборка в dist/
npm run preview      # просмотр сборки
```

### Публикация через Git (вместо ручной загрузки)

Загрузите проект в репозиторий GitHub. В Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**, выберите репозиторий и укажите:

| Параметр | Значение |
|---|---|
| Framework preset | Vite (или None) |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Environment variable | `NODE_VERSION = 20` (или новее) |

Vercel: Import Project → Framework «Vite». Остальное определится автоматически.

### Архитектура

```
src/
  core/                         — вся логика, без React
    LiveSession.ts              — связывает модули; UI работает только с ним
    camera/CameraManager.ts     — getUserMedia, фронт/основная, перезапуск после блокировки, ошибки
    comments/
      CommentProvider.ts        — интерфейс источника комментариев
      LocalCommentProvider.ts   — локальный генератор: шаблоны, вариации, «постоянные» зрители, ответы, серии, антиповторы
      AICommentProvider.ts      — заготовка под LLM через свой серверный эндпоинт (не подключена)
      CommentEngine.ts          — ритм чата: нерегулярные интервалы, волны, затишья, лимит сообщений в DOM
      profiles.ts               — 1200 вымышленных профилей (ru/uk/en), генерируемые аватарки
    viewers/ViewerEngine.ts     — плавный счётчик (1–1 000 000), плавные переходы для сценариев
    reactions/ReactionEngine.ts — сердечки напрямую в DOM, только transform/opacity
    scenarios/                  — ScenarioManager (хранение, импорт/экспорт), ScenarioPlayer (пауза/скорость), парсер таймлайна
    settings/SettingsManager.ts — настройки + валидация + localStorage
    data/                       — имена, города, библиотека фраз по 10 категориям и 4 тематикам
  ui/                           — компоненты интерфейса
  hooks/useStore.ts             — подписка компонентов на модули ядра (useSyncExternalStore)
```

Почему видео не перерисовывается: `CameraView` мемоизирован и зависит только от `MediaStream`. Чат, счётчик и сердечки подписаны на свои модули по отдельности, поэтому новый комментарий перерисовывает только список комментариев.

### Подключение AI в будущем

1. Создайте серверную функцию, например Cloudflare Pages Function `functions/api/comments.ts`. Она принимает `{ lang, theme, streamer, transcript, recent[] }`, вызывает LLM с ключом из переменных окружения Cloudflare и возвращает `{ comments: [{ username, text, lang?, replyTo?, delayMs? }] }`.
2. В `src/App.tsx` замените `new LiveSession()` на `new LiveSession(new AICommentProvider('/api/comments'))`.

Интерфейс менять не нужно. API-ключ хранится только на сервере. Если сервер недоступен, провайдер автоматически переключается на локальную генерацию.
